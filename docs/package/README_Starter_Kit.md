# Starter Kit README

This folder contains implementation-oriented starter material for EchoVault.

Use it after strategy, product and architecture are accepted.

## Recommended first implementation objective
Build the smallest paid licensing loop using one approved test track and Stripe test mode.

## Guardrail
Every implementation task should preserve this rule:

**No payment-confirmed buyer should fail to receive a license record, and no unpaid user should access high-res files.**



## Sprint 1 design lock now included
The starter repo includes implementation-ready design lock files under:

```txt
10_Starter_Kit/repo/apps/web/
```

These include the exact Tailwind config, global CSS baseline, font setup and initial UI primitives for License CTA, Checkout Drawer and Track Data Row.

The design lock is not optional. It prevents AI coding agents and developers from drifting away from the approved Dark Mode + Neon, Editorial & Monospace and Liquid Glass product language.
