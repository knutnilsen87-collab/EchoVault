# Implementation Starter Pack

## Goal
Get from documents to a minimal working codebase with correct structure and guardrails.

## Minimum starter outcomes
- Repo initialized.
- Project structure agreed.
- Coding standards wired.
- Local run path works.
- Health signal exists.
- First vertical slice chosen.
- Database migration baseline created.
- Stripe test webhook path configured.
- Object storage abstraction created.
- EchoScore fixture test added.

## First vertical slice
Artist upload → PoE → EchoScore fixture → admin approval → buyer catalog → Stripe test checkout → license record → certificate stub → signed download URL.

## Do not start with
- mobile app
- B2C streaming
- recommendations
- social features
- enterprise API
- payout automation beyond stored splits
