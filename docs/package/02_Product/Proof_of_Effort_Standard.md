# Proof of Effort Standard

## Purpose
Proof of Effort (PoE) is the minimum provenance and creative-process documentation required before a track can be sold on EchoVault.

PoE is **not** proof of copyright clearance. It is a trust and review artifact that supports buyer confidence, artist accountability and dispute investigation.

## Required PoE fields — MVP
| Field | Required | Public? | Notes |
|---|---:|---:|---|
| Creation mode | Yes | Yes | Pure AI Director / Hybrid Producer / Human-led with AI assistance |
| AI tool(s) used | Yes | Yes | e.g. Suno, Udio, Stable Audio, others |
| Prompt/process summary | Yes | Partial | Public summary should not expose sensitive full prompts by default |
| DAW/manual work | Yes | Yes | e.g. Ableton, Logic, Reason, FL Studio, mastering chain |
| Time spent | Yes | Optional | Range is enough: <1h, 1–3h, 3–10h, 10h+ |
| Samples used | Yes | Partial/private | Must declare none, owned, licensed, or public domain |
| Vocal likeness/voice cloning | Yes | Yes if relevant | Must declare no named-person imitation unless cleared |
| Artist imitation prompt | Yes | Private/summary | Must not intentionally clone named living artists unless rights cleared |
| Artist warranty | Yes | Private | Legal text required |
| Supporting files/screenshots | Optional | Private | Keep minimal to reduce sensitive data storage |

## Review rubric
Reject or request changes if:
- artist refuses rights warranty,
- required PoE fields are missing,
- named artist imitation appears without rights,
- sample provenance is unclear,
- copyrighted sample/loop use is obvious and undocumented,
- EchoScore is below threshold without override rationale,
- audio artifacts are severe,
- metadata is misleading,
- fraud/repeat abuse is suspected.

## Public PoE display
Show creation mode, tools category, manual/hybrid effort summary, EchoScore pass badge, rights-warranty status, review date and terms version. Do not expose private full prompts or sensitive production files by default.

## Data minimization
Collect enough to support trust and dispute handling, but not so much that the platform stores unnecessary sensitive creative/IP data.
