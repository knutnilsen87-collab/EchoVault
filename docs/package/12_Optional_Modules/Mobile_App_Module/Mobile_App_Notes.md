# Mobile App Module

## Status
Deferred / inactive for MVP.

## Reason
EchoVault must first validate paid B2B licensing behavior. A native mobile app adds cost without proving the core business model.

## Revisit when
- Buyer repeat usage is proven.
- Catalog browsing on mobile is a major conversion driver.
- Artists need mobile upload/review workflows.
- Native audio/background playback becomes strategic.

## MVP substitute
Responsive web.
