# Enterprise / Security-Heavy Module

## Status
Deferred beyond baseline security controls.

## Reason
MVP targets creators, small agencies and indie/SMB buyers. Enterprise controls like SSO/SAML and complex procurement would distract from validation.

## Baseline controls still required
- RBAC
- audit logs
- private storage
- signed URLs
- webhook verification
- secrets handling
- privacy policy
- data minimization

## Revisit when
- Agency/brand accounts require SSO.
- Procurement asks for security questionnaires.
- Revenue from larger customers justifies enterprise features.
