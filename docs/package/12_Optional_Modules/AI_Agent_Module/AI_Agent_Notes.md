# AI / Agent Module

## Status
Inactive for MVP.

## Reason
EchoVault uses deterministic audio analysis and structured workflows. It does not require autonomous AI agents for MVP.

## Do not implement yet
- AI moderation agents
- buyer recommendation agents
- automated legal risk classifiers
- automated copyright-clearance claims
- generative music creation inside EchoVault

## Revisit when
- There is enough labeled review/dispute data.
- Human review cost becomes a proven bottleneck.
- A human-in-the-loop evaluation harness exists.

## Guardrail
Any future agent must be advisory unless approved by legal/product. It must not independently approve tracks for commercial sale.
