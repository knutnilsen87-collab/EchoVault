# Marketplace / Ecosystem Module

## Status
Active for MVP.

## Marketplace sides

### Supply
- AI/hybrid artists and producers.
- Must submit PoE and rights warranty.
- Must pass EchoScore and human review.

### Demand
- Creators, agencies, video editors, game developers, SMB content teams.
- Need fast licensing and proof.

## Submission rules
- No public sale without completed PoE.
- No public sale without EchoScore.
- No public sale without human approval.
- Suspicious rights/sample/likeness submissions rejected or escalated.
- Track can be suspended after dispute.

## Moderation model
- Automated technical screening.
- Human review for rights/process/quality fit.
- Admin decision stored with reason code.
- Escalation path for legal ambiguity.

## Payout/revenue share logic
MVP stores fixed split at purchase time:
- suggested default: 70% artist / 30% platform.
- actual payout flow can be manual at beta.
- future payout automation via Stripe Connect.

## Review workflows
1. Submitted.
2. Analysis pending.
3. Needs human review.
4. Approved/live, rejected or changes requested.
5. Suspended if dispute or policy issue.

## Policy enforcement
Terms acceptance, artist warranty, audit logs, track suspension, dispute records and repeat-offender/fraud flags in later version.
