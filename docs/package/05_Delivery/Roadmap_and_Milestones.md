# Roadmap and Milestones

## Milestone 1 — Validation-ready specification
- Goal: Complete product/technical/legal assumptions package.
- Exit criteria: PRD approved; schema/API draft approved; legal open questions identified; buyer interview script ready.

## Milestone 2 — Internal vertical slice
- Goal: One track can move from artist upload to test license purchase.
- Exit criteria: artist upload works; admin approval works; buyer catalog shows approved track; Stripe test checkout creates license; certificate stub/download link works.

## Milestone 3 — Closed beta
- Goal: 30–100 approved tracks and 20–50 paid/committed buyers.
- Exit criteria: legal terms reviewed; review queue operational; support/dispute process in place; analytics funnel active; no P0 bugs.

## Milestone 4 — Public MVP
- Goal: Public paid licensing with controlled catalog and support coverage.
- Exit criteria: production monitoring; backup/restore tested; security checks complete; refund/dispute policy live; buyer and artist docs live.
